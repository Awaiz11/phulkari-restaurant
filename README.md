# Phulkari — Punjabi Kitchen (concept)

A concept website for a Punjabi restaurant in DHA Phase 5, Lahore.
Designed and built by NexaFlow with Next.js.

- Menu by course, with a half / full kg switch for karahi prices
- Dawat platters for families, ordered on WhatsApp
- Family hall enquiries and table bookings sent to WhatsApp
- Colours and patterns from phulkari embroidery

```bash
npm install
npm run dev
```

All text, prices and photos are in `components/data.ts`.
